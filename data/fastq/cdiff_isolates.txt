# The 37 Clostridioides difficile isolates of
#
#   Bejaoui S, Nielsen SH, Rasmussen A, Coia JE, Andersen DT, Pedersen TB, Moller MV,
#   Nielsen MTK, Frees D, Persson S. "Comparison of Illumina and Oxford Nanopore sequencing
#   data quality for Clostridioides difficile genome analysis and their application for
#   epidemiological surveillance." BMC Genomics 2025. doi:10.1186/s12864-025-11267-9
#
# deposited under BioProject PRJNA1148956 (the paper's data statement calls it ENA; the accession
# is an NCBI one and both archives mirror it). 74 runs: every isolate was sequenced twice, once on
# an Illumina NextSeq 500 and once on an ONT MinION, with no isolate missing either platform.
#
# WHY THESE ARE HERE. Every other real read collection in this project is a metagenome with no
# ground truth -- which is the whole reason for the calibration of the paper's section on
# estimating the gain without it. These are pure isolates of one known organism, typed by MLST and
# cgMLST in the source study, so they carry ground truth *below the species* and are the only data
# here that can check a sub-species refinement against something other than itself. They are not a
# substitute for the saliva or tick samples: classifying a pure culture against a single-species
# database is trivially easy, and presenting it as a real-sample result would overstate it.
#
# KEYS are the study's own isolate identifiers, B11 to B51, which are also the `sample_alias'
# values in the archive -- so a key joins directly to the source study's Table 2 for the sequence
# type. An `np' suffix marks the Nanopore run of the same isolate, as in the study. Illumina
# isolates therefore occupy two lines, one per mate, exactly as saliva_real.txt does.
#
# THE FILES ARE LOCAL, not URLs, and have to be fetched first:
#
#   sh ./bin/fetch_cdiff.sh
#
# A URL map would be the shorter route but it is not safe for paired data: Genestrip names a
# download after the map key alone (FastqMapTransformGoal.fillMap), so two URLs under one key
# would both be written to the same file and one mate would silently overwrite the other. That is
# why ticks_real.txt gets away with URLs -- single-end -- and the paired saliva runs do not.
#
# TWO PROPERTIES OF THE DATA worth knowing before drawing conclusions from read counts:
#   - 25 of the 37 Nanopore runs stop within a few hundred bases above exactly 500,000,000, the
#     signature of subsampling to 500 Mbp with the crossing read kept whole; the remaining 12 fall
#     below that cap. The deposited long reads are therefore at a uniform ~120x depth by
#     construction and say nothing about what a MinION run actually yields.
#   - Mean Nanopore read length over the project is 3,824 bp, which is essentially the 3,926 bp the
#     first Genestrip paper reports for its NanoSim reads. The two are directly comparable.
#
