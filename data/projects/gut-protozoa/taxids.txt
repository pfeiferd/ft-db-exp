# The ten protozoan genera surveyed by
#
#   Lokmer A, Cian A, Froment A, Gantois N, Viscogliosi E, Chabe M, Segurel L (2019):
#   "Use of shotgun metagenomics for the identification of protozoa in the gut microbiota of
#   healthy individuals from worldwide populations with various industrialization levels."
#   PLoS ONE 14(2): e0211139.  https://doi.org/10.1371/journal.pone.0211139
#   https://pmc.ncbi.nlm.nih.gov/articles/PMC6364966/    (PMID 30726303)
#
# Their shotgun data is in ENA under PRJEB27005 (57 runs, Illumina WGS/METAGENOMIC), the compared
# populations under PRJNA278393 and PRJNA268964.
#
# Genera only, as for the other projects of this paper.
#
# Genome availability differs sharply between these genera, which decides what a k-mer database can
# possibly distinguish. Species counts as of RefSeq release 233 and the local GenBank summary:
#
#   genus              RefSeq   GenBank   ENA assemblies
#   Cryptosporidium         8        17        -
#   Entamoeba               4         6        -
#   Giardia                 2         4        -
#   Blastocystis            2         3        -
#   Pentatrichomonas        0         1        1
#   Dientamoeba             0         0        0
#   Iodamoeba               0         0        0
#   Endolimax               0         0        0
#   Chilomastix             0         0        0
#   Enteromonas             0         0        0
#
# The last five have no assembled genome in RefSeq, GenBank or ENA. What ENA does hold for them are
# a few hundred short 18S rRNA barcoding entries -- 10 KB to 200 KB per genus in total, spread over
# near-identical copies of one conserved marker gene, against tens of megabases for a real protozoan
# genome. Adding those via additional.txt would do harm rather than good: reads from anywhere else
# in the genome would still match nothing, while the conserved 18S would attract reads from across
# the whole gut microbiome and produce false assignments.
#
# The study itself hit the same wall and solved it by splitting its method: "To detect Blastocystis
# sp., Giardia intestinalis, Cryptosporidium hominis and C. parvum, we used whole-genome data,
# while, for the other species (including all Entamoeba spp.), we used complete SSU rRNA gene
# sequences." It even downgraded Entamoeba to the marker although genomes exist for E. histolytica
# and E. dispar, "in order to obtain comparable data for a larger number of Entamoeba species", and
# excluded Retortamonas and Pentatrichomonas altogether because their public SSU sequences were
# "either very short or not of human origin".
#
# That route is not open to us, and the difference is not one of effort. The study answers "is genus
# X present in this sample?", for which a single hit on a conserved marker suffices. A k-mer
# database answers "which taxon does this read belong to?", which a marker gene cannot support. The
# five genera therefore stay in this list to document the intent -- reads from them are
# unclassifiable by construction -- and the database rests on the remaining five.
